# 🌌 Skanda BS – Interactive AI Engineer Portfolio

A cutting-edge, vibrant, interactive developer portfolio for **Skanda BS** (AI Engineer & Autonomous Systems Builder), featuring live architecture simulators, an interactive agent CLI terminal, GitHub repository sync, and seamless resume preview/download.

---

## 🌟 Key Features

1. **Cyber-Luxe & Glassmorphic UI**:
   - High-contrast glowing neon aesthetic powered by Tailwind CSS.
   - Dynamic canvas particle constellation background reacting to mouse physics.
   - Interactive 4-theme palette switcher:
     - 🌌 **Cosmic Cyber** (Default)
     - ⚡ **Synthwave Neon**
     - 🌿 **Matrix Mint**
     - 🌅 **Solar Flare**
   - Synthesizer sound effects built via the native Web Audio API (zero audio files needed).

2. **Live Interactive Architecture Lab**:
   - **AgentShield Live Interceptor**: Interactive probe tester simulating prompt injection defense, PII masking, risk scoring, and emergency kill-switch controls.
   - **Debate AI Multi-Model Arena**: Multi-agent arbitration simulator comparing responses from GPT-4o, Gemini, Grok, and Claude with real-time consensus synthesis.

3. **Interactive Agent CLI Terminal**:
   - Run interactive terminal commands (`help`, `skills`, `projects`, `agentshield`, `debate`, `indic`, `stats`, `resume`, `contact`, `hire`, `matrix`, `clear`).
   - Built-in Matrix rain Easter egg!

4. **Projects & GitHub Ecosystem**:
   - Direct integration with [@Skanda001](https://github.com/Skanda001) repositories:
     - **AgentShield**: AI Agent Security & Governance Platform.
     - **Debate AI**: Multi-Agent Answer Reliability System ([Live on Render](https://debate-ai-1-frontend.onrender.com)).
     - **IndicRAGHal**: Cross-Lingual Hallucination Detection for RAG in Indian Languages.
     - **ByteArena**: Competitive multiplayer challenge arena in TypeScript.
     - **AI-Internship-Agent**, **Email Support Agent**, **CWT Quant Pipeline**.
   - Simulated annual git activity heatmap.

5. **Integrated Resume Viewer & Download**:
   - Bundled with Skanda's official resume (`Skanda_BS_Resume.pdf`).
   - In-page preview modal with one-click direct download.

## 🚀 How to Run Locally

You can simply open `index.html` in any web browser!

Or launch a local development server using Python:

```bash
# In this directory:
python -m http.server 3000
```

Then visit: [http://localhost:3000](http://localhost:3000)

---

## 🌐 Deployment

### Deploy to GitHub Pages:
1. Push this directory to a GitHub repository under `Skanda001`.
2. Go to **Settings** > **Pages** > Select branch `main` or `master` > Click **Save**.
3. Your portfolio will be live at `https://Skanda001.github.io/<repo-name>/`!

### Deploy to Vercel:
```bash
npx vercel
```
Or drag-and-drop the directory into the [Vercel Dashboard](https://vercel.com).
